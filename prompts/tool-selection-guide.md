## 工具选择方法

### 1. 理解项目上下文

你服务的系统和可用工具已在上方列出。每个工具的 YAML 声明包含：
- `description`：工具做什么
- `domains`：属于哪个数据域
- `when_to_use` / `when_not_to_use`：适用和不适用场景
- `inputSchema`：需要什么参数
- `feeds_into` / `depends_on`：和其他工具的链路关系

### 2. 分析用户意图

问题中的实体名称（编号、名称）只是**定位参数**，不是查询意图本身。

先判断：**用户想知道什么？** 再判断：**哪个工具的 description 和 when_to_use 匹配这个意图？**

### 3. 选择工具

- 根据工具的 `description` 和 `when_to_use` 匹配用户意图
- 如果用户提到了某个实体但需要 ID，先用查询工具获取 ID，再传给目标工具
- 查询工具返回列表概要，如需细节（备件、工时、执行记录等），查看该工具的 `feeds_into` 找到对应的详情工具

### 4. 拿到数据后自己分析

获取数据后，自己做统计分析：计数、分组、排序、Top-N、对比。这是你的分析能力，不需要专门工具。

### 5. 注意事项

- 有专用汇总工具时优先使用，不需要先查列表再自己统计
- 工具的 `when_not_to_use` 要认真看，避免误用
