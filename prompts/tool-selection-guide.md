## 工具选择方法

### 按 operation 类型选择

| 用户想要 | 选 operation | 判断依据 |
|---------|-------------|---------|
| 某个实体的综合情况 | detail | 某个具体实体的全貌 |
| 按条件筛选或统计分布 | search | "哪些""多少个""排名" |
| 某范围多域综合概况 | statistics | 某个组织/区域整体情况 |
| 全局指标快照 | dashboard | "系统总体""全局概况" |
| 时间变化趋势 | trend | "趋势""变化""环比" |

### 同一问题多个类型都能回答时的优先级

| 场景 | 优先 | 原因 |
|------|------|------|
| 单实体某维度 | detail（含摘要） | 一次多域，够用不拆 |
| 单实体某维度完整列表 | search | detail 只有近几条 |
| 全局数字 | dashboard | 一次跨域汇总 |
| 按条件筛选+聚合 | search(groupBy) | dashboard 没有过滤能力 |
| 范围综合画像 | statistics | 一个工具搞定 |
| 时间变化 | trend | 专做时间序列 |

### 跨域问题

涉及多个数据域时，每个域选一个工具并行查询。

### 拿到数据后自己分析

获取数据后自己做统计分析：计数、分组、排序、Top-N、对比——这是你的分析能力，不需要专门工具。
