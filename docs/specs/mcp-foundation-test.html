1. 地基架构

MCP 工具层地基 — 三层结构 eam-api.ts EAM REST API 客户端 ├ getToken() 自动登录 + token 缓存 + 续期 ├ eamGet(path, params) 通用 GET（自动带 Authorization + tenant-id） ├ eamPost(path, body) 通用 POST └ eamParallel(...calls) 并行调用多个 API（Promise.allSettled） resolvers.ts 公共 identifier 解析器（所有工具共用） ├ resolveEquipment(identifier) 设备: name/code/ID → Equipment ├ resolveProductionLine(identifier) 产线: name/code/ID → ProductionLine ├ resolveDepartment(identifier) 部门: name/ID → Department ├ getEquipmentIdsByProductionLine(lineId) 产线 → 设备ID列表 └ getEquipmentIdsByDepartment(deptId) 部门 → 设备ID列表 handlers/equipment-profile.ts 第一个工具 └ eam.equipment.profile 设备全景（基础+KPI+故障+维修+保养+巡检+BOM+生命周期） 认证方式: POST /admin-api/system/auth/login + tenant-id header → accessToken 所有请求: Authorization: Bearer {token} + tenant-id header

匹配策略

identifier 解析优先级: 1. 纯数字 → 直接按 ID 查 /equipment/get?id= 2. 字符串 → keyword 搜索 /equipment/page?keyword= 3. 匹配策略: exact match > startsWith > contains 4. 唯一匹配 → 返回实体 5. 多个匹配 → 返回候选列表（最多 5 个），AI 追问用户 6. 无匹配 → 返回 none
