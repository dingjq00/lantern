整体数据流

用户查询 → prompt-assembler（6层组装 ~14.5k tokens）
→ LLM.think() Round 0（5步模板：意图→候选→审查→规划→验证）
→ MCP callTool（执行）→ validator（校验）
→ 观察注入（结果JSON≤4000字 + 事实对比 + 域覆盖 + 校验警告）
→ [快速完成?] 单域+全成功+有数据 → 跳过审查
→ LLM.think() Round 1（审查：finish / 补充 / 放宽重试）
→ [追查] Round 2... max=2
→ data-digest（stats前置 + 领域KPI） + 原始JSON
→ LLM.summarize()（独立调用，隔离上下文）
→ StructuredResult
