LLM 算术/计数错误 (7题) — DeepSeek 从长 JSON 列表中统计计数时出错（如149条数据统计出124）。这是 LLM 固有局限，prompt 无法解决。解法方向：MCP handler 层预计算统计值，不依赖 AI 遍历原始数据。
