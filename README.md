# MES AI Explorer

探索性项目：为 MES/EAM 系统构建 AI 自然语言交互层。

## 愿景

未来的 MES = 一个输入框。用户不需要学系统操作，用自然语言查询、分析、录入制造数据。

## 技术方向

语义层 + 向量路由 + 知识图谱 + LLM（不走 Text-to-SQL）

## 项目状态

**Phase 0: 调研** — 已完成行业方案调研和技术可行性分析，见 `docs/research/`
